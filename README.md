# Checkpoint 1.3.0 — Gaming news reader

خبرخوان محلی و بدون وابستگی برای پنج رسانه انگلیسی‌زبان:

- GameSpot
- Game Informer
- Push Square
- Gematsu
- Video Games Chronicle (VGC)

برنامه صفحه‌های خبر را مستقیم می‌خواند، صفحه‌بندی یا Load More را تا رسیدن به آخرین خبر شناخته‌شده دنبال می‌کند و موارد تکراری را حذف می‌کند. عنوان هر خبر بدون ترجمه یا بازنویسی، دقیقاً با متن استخراج‌شده از سایت مرجع نمایش داده می‌شود.

## اجرا

Python 3.10 یا جدیدتر کافی است و پکیج جانبی نیاز نیست:

```sh
python3 server.py
```

سپس `http://127.0.0.1:8766` را باز کنید. پورت `8765` برای برنامهٔ محلی دیگر آزاد می‌ماند. برای پورت دلخواه از `python3 server.py --port 9000` استفاده کنید.

در اولین بررسی، صفحه اول هر منبع به‌عنوان نقطه شروع ذخیره می‌شود. در بررسی‌های بعدی، خزنده صفحه‌های بعد را تا رسیدن به یکی از شناسه‌های ذخیره‌شده ادامه می‌دهد؛ در نتیجه محدود به صفحه اول نیست. سقف ایمنی هر منبع ۵۰ صفحه است. اگر این سقف یا خطای میان‌راهی رخ دهد، وضعیت آن منبع جلو نمی‌رود تا اجرای بعدی خبرهای باقی‌مانده را دوباره دریافت کند.

سابقه خبرها در `localStorage` مرورگر نگهداری می‌شود. دریافت خبر و عکس به اینترنت نیاز دارد؛ هیچ سرویس ترجمه یا API Key لازم نیست.

## به‌روزرسانی و تصاویر

برای به‌روزرسانی، سرور قبلی را در ترمینالش با `Ctrl+C` ببندید، نسخه جدید را در پوشه‌ای جدا استخراج کنید و `python3 server.py` (در ویندوز `py server.py`) را از همان پوشه اجرا کنید. هنگام اجرا باید `Checkpoint 1.3.0` و آدرس `http://127.0.0.1:8766` چاپ شود. نسخه برنامه در پایین صفحه نیز نمایش داده می‌شود. اگر پیام اجرای سرور قدیمی دیده شد، هنوز پردازش نسخه قبلی باز است.

تصاویر VGC و Gematsu از `data-srcset` نیز خوانده می‌شوند. آدرس تصاویر به حافظه موقت یا فایل نگاشت وابسته نیست؛ تصاویر مفقودِ خبرهای قدیمی از metadata خود مقاله بازیابی می‌شوند. فایل واقعی تصاویر در پوشه نادیده‌گرفته‌شده `.image-cache` ذخیره می‌شود و بعد از ری‌استارت دوباره قابل استفاده است. نیازی به پاک‌کردن سابقه مرورگر نیست. در صورت رد دسترسی به تصویر توسط ناشر، مرورگر یک‌بار URL مستقیم را بدون Referer امتحان می‌کند و سپس امکان Retry image می‌دهد.

## بررسی

```sh
python3 -m unittest discover -s tests -v
node tests/test_refresh.cjs
```

تست اختیاری مرورگر برای توسعه‌دهندگان دارای Playwright و Chromium:

```sh
node tests/test_images.cjs
```

این تست تصاویر زنده هر سه منبع Push Square، Gematsu و VGC را در Chromium رمزگشایی می‌کند؛ سپس ری‌استارت سرور و بازیابی سابقه قدیمی دارای token خراب را بررسی می‌کند. برای مسیر سفارشی مرورگر، `CHROMIUM_PATH` و برای مفسر Python، `PYTHON` را تنظیم کنید. اجرای خود برنامه همچنان فقط به Python نیاز دارد.
